JIDE 交互原型 · 评审引导

本原型演示业务设计中的三大支柱与关键交互,全部数据为脚本模拟,不含真实执行。建议按顺序体验:
1
自测闭环(差异化核心)在中间「Agent 对话」页签点「修复购物车总额浮点 bug」:观察计划推进 → diff 双全文 → 智能选测 → 浏览器自动化(点击/截图)→ 检查项沉淀 → 记忆建议卡片;后台变更的页签会打绿点。
2
评审与 Gitagent 的自动提交与记忆建议进入右侧「评审队列」等你确认(通过 / 追问),右侧窄菜单在 计划/评审 间切换并可收起;顶栏是分离的 Git 状态条(项目/工作区/分支/远程)+ 独立的「同步」「拉取请求」按钮;变更明细在左侧「源代码管理」。
3
隔离工作区 + 运行三档顶栏切换 Default ⇄ worktree;右上「运行」三档(Agent 自测 / 人侧预览 / CDP 后门);测试失败「问 agent」;侧栏「记忆」看预算与整理。
